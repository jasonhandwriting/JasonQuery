# HexBox and Bit Controls

This directory contains vendored and locally modified source code from
**Be.HexEditor**, including the `Be.Windows.Forms.HexBox` control and the
related `BitControl` / `BitInfo` components.

## JasonLibrary integration

The source code is compiled directly into `JasonLibrary` and has been adapted
for JasonQuery, including namespace integration, project integration, and
local maintenance changes.
